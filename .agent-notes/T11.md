## Observation: generated models omit `end` on multiline-bracket entries
- **Context**: Emitting TextMate from model/generated (T11).
- **Finding**: e.g. CommandSkinParamMultilines (kind multiline-bracket) has no `end` Part. `tools/emit/lark.py:204` does `entry['end']` and will KeyError on such models; textmate.py defaults the end (`^\s*\}` for bracket, `$` otherwise).
- **Impact**: lark emitter needs the same tolerance before running on model/generated.
- **Confidence**: High
