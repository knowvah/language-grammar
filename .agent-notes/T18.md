## Observation: a `{` alone on the next line belongs to the declaration (syntaxWithFinalBracket)
- **Context**: the 8 plantuml-ts / 9 pdiff class FRs failing at a `{` line.
- **Finding**: `CommandMultilines2.isValid` (:84-92) and `SingleLineCommand2.isValid`/`isValidBracket` (:84-85, :94-99, :109-119) accept `decl` + a line that is exactly `{` (BlocLines.eventuallyMoveBracket :358-371) for commands overriding `syntaxWithFinalBracket()`. At 97a5992 only CommandCreateClassMultilines and CommandPackage override it. A blank line in between breaks it. Modeled as joiner-only `join` (max_lines 1) entries after the rule, which emitters skip.
- **Impact**: any family whose factory registers CommandPackage (description, ...) has the same FR shape; reuse the join.
- **Confidence**: High (oracle-verified fixtures)

## Observation: the group stack starts with the root; one extra `}` is accepted
- **Context**: FA zalulo (class nested in a class body leaves a stray `}`).
- **Finding**: `CucaDiagram.endGroup` (net/atmp/CucaDiagram.java:367-374) pops `stacks`, which holds the root. A first extra `}` empties it and is accepted; afterwards any command needing the current group fails (hide/show of entities, notes, links, legends, packages, classes) while titles, skinparams, scale, style, sprites, pragma, `hide <visibility> members` still pass; a second extra `}` fails at once. Probed one command at a time.
- **Impact**: families with groups (description, state, usecase) can reuse the `class_orphan` pattern (class-groups `CG_ORPHAN_UNSAFE`).
- **Confidence**: High (jar probes)

## Observation: patches are uniform across contexts, so per-state behavior needs head entries
- **Context**: `allowmixing` (CommandCreateElementFull2.java:197-198 fails without it) and group depth.
- **Finding**: overrides/inserts apply to every context, including copies spliced by `include: gen-x#main`. A model can define its own `main` (it shadows the generated one) and several state contexts that each splice `gen-x#main` after a few head entries. Head entries run before the whole generated list, so each must be a line no earlier upstream rule takes, or exclude those lines (a lookahead), or the ordering changes.
- **Impact**: reusable for any sticky diagram state; tests that collect entries across all contexts see duplicates (test_style, queued).
- **Confidence**: High

## Observation: the TextMate emitter breaks recursive regexes; COLOR_SPEC is too big for PCRE2 in a long rule
- **Context**: test_textmate PCRE2 compile of the emitted grammar.
- **Finding**: textmate_regex demotes every group to non-capturing, so `(?(DEFINE)(?<n>...))` / `(?&n)` become invalid; only `reject` and joiner-only `join` entries (dropped by emitters) may carry them. Shared COLOR_SPEC expands the 160-name table several times: a class head using it emitted a 30k-char regex that PCRE2 rejects as too large; the generated COLOR leaf is equivalent and compact.
- **Impact**: put JSON-like recursive validation in rejects/joins; use COLOR (gen-shared) in long heads.
- **Confidence**: High

## Observation: JSON blocks in class diagrams are concatenated without separators
- **Context**: neticu FR (nested JSON) and JSON fixtures.
- **Finding**: CommandCreateJson.finalVerification (:155-161) keeps scanning until `"{" + body + "}"` or the body alone parses (:163-195); body lines are joined with no separator, so `"a": tru` / `e` and `1` / `2` (= 12) parse, and `//` comments never do (JsonParser skipComment waits for a newline). Single-line `json J TRUE` / `007` fail (case-sensitive literals, no leading zero) though the regex is case-insensitive.
- **Confidence**: High (oracle-verified inline cases)

## Observation: `<style>` via common makes Lark slow on blocks with a style body
- **Context**: Lark sample of 200 plantuml-ts class blocks: 0 disagreements, 11 timeouts.
- **Finding**: class/maxosa-84-juci042 parses in 0.4 s with `common` minus `style`, 16.7 s with `[gen-class-diagram, common]` alone, 18.4 s with the full class model. The class sub-models add about 1 s at most.
- **Impact**: style (T33) owns the Lark cost; the vega slice is unaffected (28/28 agree, no timeouts).
- **Confidence**: High (variant grammars timed)

## Observation: the stock jar prints error messages with `-syntax` on stdin
- **Context**: classifying entity-state FAs.
- **Finding**: `java -jar <stock jar> -syntax < file.puml` prints `ERROR`, the line and the message ("Bad name", "Not a package: X", ...). Quick way to name the upstream error site for a classification cite.
- **Confidence**: High
