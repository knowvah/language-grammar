## Observation: running one factory alone shows that family's own error message
- **Context**: `java -jar <jar> -syntax` reported "Syntax Error? (Assumed diagram type: sequence)" for state blocks that StateDiagramFactory rejects for another reason.
- **Finding**: `PSystemErrorUtils.merge` keeps the error with the highest score, which often comes from another factory. A small harness that calls `new StateDiagramFactory().createSystem(null, UmlSource.createWithRaw(data, false, data), null, pa)` per block, with `pa` read reflectively from `BlockUml.preprocessingArtifact` (a null artifact NPEs), prints the factory's own message and line. `-syntax` line numbers are 0-based.
- **Impact**: family tasks can name the exact upstream error site for classifications and gap fixtures; swap the factory class per family.
- **Confidence**: High

## Observation: state diagrams run three passes and reset the group stack per pass
- **Context**: modeling composite states and concurrent regions.
- **Finding**: StateDiagram requires ParserPass ONE, TWO, THREE (StateDiagram.java:65-68). Links run only in TWO, field lines only in ONE, notes on entities in THREE. `startingPass` cuts the group stack back to the root (net/atmp/CucaDiagram.java:161-166) but does not restore an empty stack. A `}` that closes a concurrent region opened at the root pops the region and the root (StateDiagram.endGroup :210-217), so the next group access, at the latest the region line in pass TWO, throws IllegalStateException. A `}` at the root without a region is "No inner state defined". An unclosed `{` is accepted.
- **Impact**: modeled with contexts main / main_concurrent / state_body; closers are per-context head entries.
- **Confidence**: High (jar and state-only probes)

## Observation: entry/exit/pin stereotypes fail only at the root, and only as the whole label
- **Context**: spec item "declarations with all stereotypes".
- **Finding**: CommandCreateState fails when the new state's parent is the root and `Entity.getEntityPosition()` is not NORMAL (CommandCreateState.java:236-237, abel/Entity.java:327-347). That holds when the full stereotype label equals `<<entrypoint|exitpoint|inputpin|outputpin|expansioninput|expansionoutput>>` ignoring case. `<<port>>` throws UnsupportedOperationException (EntityPosition.java:154-155). `<<a>> <<b>>`, `<< exitpoint >>`, `<<(E,red)exitpoint>>`, `P.X` and `"P.X"` are accepted. Inside a composite, frame or root-level region all are accepted. A state that already exists (reused by name from a composite, or declared as `<<choice>>`) is accepted too, which the model cannot see.
- **Confidence**: High

## Observation: names ending in the separator throw, but `set separator` is diagram-global
- **Context**: deciding whether to model `state A.` / `A..B --> C`.
- **Finding**: quarkInContext fails on a name that ends with the separator or contains it twice (CucaDiagram.java:258-259, :290-297), in every name slot (state, composite, frame, field, link, note). `set separator none|::` turns that off for the whole diagram, and links run in pass TWO with the separator left by pass ONE. A context stack cannot change frames below the top, so the model leaves it as a gap (FA direction) instead of risking FRs.
- **Confidence**: High

## Observation: lookahead-only differences vanish in Lark and make Earley ambiguous
- **Context**: a first design narrowed CommandCreateState with `(?!...)` and accepted the same lines through a `(?=...)` head in nested contexts.
- **Finding**: the Lark emitter drops zero-width terminals, so both entries became the same rule. On plantuml-ts class/somuke-94-buzi673 (theme-expanded, 166 lines) parsing took 34 s, against 12.5 s without the pair. The emitters cannot express a context-dependent reject anyway.
- **Impact**: keep context-dependent rejects as interpreter-only `reject` heads; do not add lookahead-gated twins of generated rules.
- **Confidence**: High (variant grammars timed)

## Observation: class model accepts lines the jar rejects (for the class family's cleanup)
- **Context**: state probes with full dispatch.
- **Finding**: `@startuml` / `A. : x` / `@enduml` is accepted by the interpreter as CLASS, but every jar factory rejects it. `frame A. {` / `}` is accepted as CLASS by the interpreter and as DESCRIPTION by the jar.
- **Confidence**: High (oracle-verified)
