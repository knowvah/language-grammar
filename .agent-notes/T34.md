## Observation: PSystemSingleLineFactory is stricter than "one keyword line"
- **Context**: refining the T13 embedded single-line models (license, version, ...).
- **Finding**: removeInitialNoise drops only leading lines that are exactly "" or start at column 0, case sensitive, with `skinparam `, `skinparamlocked ` or `!pragma ` (core/UmlSource.java:79-106; `skinparam ` with a trailing blank and nothing else is noise, ` skinparam x` is not). Then the source must be exactly start + one line + end (command/PSystemSingleLineFactory.java:75-76): a blank line after the command, or a whitespace-only line before it, makes the jar reject. executeLine gets the untrimmed line (:91-95), so `  license` is rejected and `license \t` accepted. Modeled with `trim: false`, a `needs`/`gives` flag for noise-only bodies and a reject-everything `sl_done` context (model/diagrams/single-line-base.yaml).
- **Impact**: any non-command factory that counts lines needs the same treatment; trimmed matching hides it.
- **Confidence**: High (oracle probes, tests/fixtures/single-line)

## Observation: four Java case-insensitivity flavours, each with different non-ASCII matches
- **Context**: exact keyword regexes for the single-line factories.
- **Finding**: Java `(?i)` / Pattern2 CASE_INSENSITIVE (no UNICODE_CASE) and UBrex (ubrex/CaseMode.java:41-45) fold ASCII only. `String.equalsIgnoreCase` (apple, rip, charlie, dedications) also equates U+0131 and U+0130 with i, U+017F with s, U+212A with k. `StringUtils.goLowerCase` (`toLowerCase(Locale.ENGLISH)`, listfonts, emoji, openiconic) maps only U+212A onto an ASCII letter; U+0130 lowers to two chars. Python `regex` IGNORECASE matches U+0130, U+212A and U+017F but not U+0131, so `ci: true` is wrong in both directions. The family models use explicit classes (`[iIıİ]`, `[kKK]`, `[sSſ]`). Java `\s` is ASCII; Pattern2 `%s` adds NBSP.
- **Impact**: generated `ci: true` regexes accept `licenſe`-like lines the jar rejects (help commands were narrowed here); a translator-level fix would need per-engine case rules.
- **Confidence**: High (oracle probes)

## Observation: PSystemBasicFactory bodies (ditaa, math, latex, dot)
- **Context**: D4 opaque types.
- **Finding**: After noise removal, leading lines that trim to empty are skipped (command/PSystemBasicFactory.java:84-85) and the empty-description error needs exactly two lines left (:88-90). So `@startditaa` + `   ` is accepted (a whitespace line is not noise) while `@startditaa` + `skinparam a b` is rejected (noise only). dot's initDiagram returns null (directdot/PSystemDotFactory.java:62-66): the header must be the first surviving line, matched untrimmed with ASCII `\s`; a dot body with only a whitespace line returns null and the jar throws IllegalStateException in PSystemErrorUtils.merge (:132), which the oracle reports as a harness error with empty `preproc`.
- **Impact**: interpreter verdicts of such blocks with no preproc are meaningless (the empty text is dispatched as a bare body).
- **Confidence**: High (oracle probes; merge crash reproduced with `java -jar ... -syntax`)

## Observation: HelpFactory has no CommandNope; crash type is last-wins and reported as BPM
- **Context**: help and crash models.
- **Finding**: HelpFactory registers only the five help commands (help/HelpFactory.java:61-67), so a blank line in a `@startuml` help block is a syntax error; HELP is reachable only from `@startuml` (core/DiagramType.java:53-63), `@starthelp` is an unknown keyword (accepted as PSystemUnsupported). `crash when <type>` overwrites the type (crash/CommandSelectCrash.java:86): finalizing then drawing is accepted, drawing then finalizing rejected; parsing fails at its line via ProtectedCommand. CrashDiagram passes DiagramType.BPM (crash/CrashDiagram.java:58), so the oracle types accepted crash blocks BPM.
- **Confidence**: High (oracle probes)

## Observation: arithmetic acceptance in single-line factories
- **Context**: egg, sudoku, openiconic, dedication.
- **Finding**: PSystemEggFactory accepts a line whose letters (base 26) XOR-decode a ciphertext into printable text; no key up to 4 bytes passes, and a key built from a chosen 21-byte plaintext gives a 35-letter line the jar accepts (tests/fixtures/single-line/gap/egg-constructed.puml). Sudoku seeds above Long.MAX_VALUE in base 36 (`1y2p0ij32e8e7`) throw in parseLong and are rejected. `openiconic X` needs X (lowercased) to be one of the 223 `openiconic/*.svg` resources. Dedication length is `String.length()` (UTF-16): `baraye` + 10 emoji is accepted.
- **Confidence**: High (oracle probes)

- **Context**: choosing neg fixtures under full `@startuml` dispatch.
- **Finding**: `timing` accepts `listopeniconi` and `  listopeniconic` through CommandChangeStateByPlayerCode (rule match verified; that it splits at the `is` inside the word is inferred, not traced); `gen-list-sprite-diagram` accepts `lİstsprite` (Python case folding); `description` accepts `#listsprite`. - **Confidence**: High (oracle probes)

## Observation: Lark's eval_escaping collapses `\\"` in regex terminals
- **Context**: pos/dot-escaped-quote rejected by Lark only.
- **Finding**: lark doubles `\\` and then replaces `\"` with `"` in `/.../` literals, so the regex `\\"` becomes `\"`. `[\\]"` survives. Queued in reports/queued-shared-changes.md.
- **Confidence**: High (minimal Lark repro)
