## Observation: ci-literal convention and ASCII shorthands
- **Context**: Choosing W3C notation conventions.
- **Finding**: ci literal `class` -> `[Cc] [Ll] [Aa] [Ss] [Ss]` (upper case first, space-separated items). `\s \d \w` use ASCII ranges; `^ $ \A \z \Z` are dropped. Class ranges keep source order; ci/negated-shorthand-in-class ranges are normalised.
- **Impact**: T35 docs should quote this convention; header of dist/plantuml.ebnf repeats it.
- **Confidence**: High
