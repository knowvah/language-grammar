## Observation: Python `re` rejects `\p{L}`, which Pattern2 macro expansion emits
- **Context**: Implementing regex validation in tools/model/load.py (T04).
- **Finding**: `%pLN` expands to `\p{L}\p{N}`; `re.compile` raises on `\p{..}`, and Java
  named groups `(?<n>..)` too. The loader compiles with the `regex` module (V0) instead.
- **Impact**: Generators (T06+) may emit `\p{..}`; do not "fix" the loader back to `re`.
- **Confidence**: High

## Observation: jsonschema oneOf errors need branch selection
- **Context**: Reporting unknown keys inside Part / entry oneOf schemas.
- **Finding**: `best_match` picks the wrong branch; load.py picks the branch with the
  fewest errors (`_leaves`) so the unknown key's JSON pointer is reported.
- **Impact**: Keep branches discriminated by distinct required keys.
- **Confidence**: High
